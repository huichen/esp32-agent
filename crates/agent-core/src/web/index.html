给大模型的工作流

  1. 发现：inventory / i2c_scan / i2c_identify 找到真实接线。
  2. 建模：manifest_describe 拿到清单 schema、原语和示例。
  3. 写入：manifest_apply 校验并生效，无需重启、无需重烧。
  4. 验证：tools/list 里出现新工具，直接调用。
  5. 迭代：结果不对就改清单再应用，工具列表实时更新。

模型连接

模型地址必须是明文的 http 地址（板子上没有 TLS）；key 只写进 NVS，读回来时只显示是否已设置。

调度 tick 就是队列最快多久被取走一次（200–5000 ms，默认 1000）：板子每个 tick 重新读它，所以改完下一个 tick 就生效，不用重启。

还没有事件。停在这一页时，运行的每一步都会实时出现在这里。

由 /api/agent/stream 推送（SSE）：板子空闲 30 秒或单条连接满 120 秒会主动断开，浏览器自己重连并从最后一条事件续上，页面不重发任何东西。

定时任务

“每 N 秒”和“HH:MM”二选一：填秒数按周期触发，填 HH:MM 每天触发一次；到点的提示词会排进同一条智能体队列。

传感器规则

规则每轮先调用工具读一次值，命中才排提示词；min_interval_s 防止一条规则持续刷屏。
