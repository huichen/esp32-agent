How a model configures this board

  1. Discover: inventory / i2c_scan / i2c_identify.

  5. Iterate: edit and apply again as often as needed.

Conversation

Goal

–

State one objective and the board works through it alone: one small step per iteration, each result written down as a note that the next iteration is prompted with. A reply saying GOAL MET ends it; GOAL BLOCKED, three failures in a row or the iteration budget ends it too. One goal at a time, and the notes live in NVS, so they are short.
